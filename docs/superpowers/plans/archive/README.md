a habit rather than a status: the work landed and the boxes never got marked.
Confirmed at archive time by looking for each plan's headline type in
`Sources/` (`StreamResolver`, `AlbumGroup`, `DeviceSyncQueueStore`, `DSFFile`,

why several subsystems are shaped the way they are. Do not treat an unticked
box here as work outstanding.
